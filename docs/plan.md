# Plan

This file is a seed, and it is meant to disappear. It holds what was settled before the first commit. The work itself is in this repository's issues. As each line below gets its lasting home, delete it here. When nothing is left, delete the file: #2 tracks that.

typescript-quality exists so that starting a TypeScript project doesn't begin with researching quality tools and collecting past decisions about them all over again. [ruby_quality](https://github.com/Kerrick/ruby_quality) does the same for Ruby.

## Settled

- **A first version is done** when a heavily agent-driven TypeScript project started from it goes at least as well as a Ruby project started from ruby_quality.
- **How a project receives it is open.** It could be a command that sets a repository up, a template repository, or something else.
- **No choice of tool or setting is settled yet.** The first step is a draft to try, and the maintainer tries it on real projects himself.
- **License:** MIT-0 for code, and CC0-1.0 for documentation. Copyright Kerrick Long. A starting point for other projects is no good if it needs attribution.
- **Releases happen on GitHub, freely:** tags and GitHub releases are cut whenever the trunk is ready. Versions are `0.X.Y` only, three plain integers: no prerelease form (no `-rc.1`, no `.pre.`), and no `1.0.0` or higher until the maintainer says so. Nothing goes to a registry outside GitHub (npm or any other) until the maintainer approves it.

Nothing else is settled.
